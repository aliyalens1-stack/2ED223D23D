# Field Cognition Debrief Template
## R1 · body_paint runtime · post-inspection reflection

> **Заполняется в течение 30 минут после inspection.**
>
> Не раньше — должен пройти adrenaline drop, чтобы инспектор
> мог отделить «как я работал» от «что я думаю об инструменте».
>
> Не позже — детали уходят за 60 минут, остаются только нарративы.
>
> Структура — три голоса в одной комнате:
> **инспектор** (subject), **наблюдатель** (witness), **runtime** (текст полей,
> зафиксированный в `field_test_protocol.md`).

## ⑥ Decision triggers (для следующего шага)

> Это **итог**, который определяет, что делаем в коде ДО R2.
> Каждая строка — либо ✅ (готово, не трогаем), либо 🔧 (правим в R1.5), либо ⏸ (на R3+).

| Сигнал                                                | Действие |
|--------------------------------------------------------|----------|
| Inspector смотрел на телефон > на машину ≥ 3 раза     | 🔧 R1.5: упростить severity / убрать text input mid-flow |
| Friction-теги в одной категории ≥ 2                   | 🔧 R1.5: переработать эту mini-flow |
| Photo flow — performative, не organic                 | ⏸ R3: inline camera ускорит, ждать |
| Voice answers ≥ 3 раз похожие                         | ⏸ R3+: фиксируем direction, не строим |
| Silent skips ≥ 2                                      | 🔧 R1.5: усилить визуальный сигнал «не отмечено» |
| Severity calibration drift к концу                    | 🔧 R1.5: pulse-mark на item 6 («ещё 5 пунктов») |
| Environmental break-points ≥ 3                        | 🔧 R1.5: contrast / large-tap / glove-mode |
| Q3 ответ = «бумага»                                   | 🛑 Stop R2. Runtime не готов. Iterate R1. |
| Q3 ответ = «runtime»                                  | ✅ R2 разрешён |
