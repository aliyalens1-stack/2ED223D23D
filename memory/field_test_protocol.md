# Field Cognition Capture Protocol
## R1 · body_paint runtime · in-field observation sheet

> **Это не QA-документ.** Это документ для наблюдения за тем,
> как runtime ведёт себя в руках инспектора в реальных условиях:
> внимание, усталость, естественность ритма, качество evidence.
>
> Заполняется **во время** inspection. Дебриф — отдельный документ
> (`field_test_debrief.md`), заполняется в течение 30 минут **после**.

---

## ⚠ Правила для observer'а (не для инспектора)

Перед запуском теста — **наблюдатель должен:**

1. **Не объяснять UX.** Не говорить «новый runtime», «item-by-item flow»,
   «progressive cognition». Сказать буквально: *«Проверь машину как обычно.»*
2. **Не вмешиваться.** Даже если видно, что инспектор пропустил item или
   забыл фото — молчать. Записать в Friction.
3. **Не объяснять кнопки.** Если спрашивает «а что это?» — записать
   вопрос как Confusion-signal, ответить *«как считаешь нужным».*
4. **Сидеть сбоку.** Не за спиной. Не следить за экраном демонстративно.
5. **Не комментировать.** Ни одобрительно, ни критично. Performed behavior
   = испорченные данные.

## ② In-flight item log

> Заполняется **по ходу**, одной рукой. Стрелка `→` рисуется в момент

> Время — по внешнему секундомеру, **НЕ по таймеру в телефоне.**

## ④ Observer side-notes (only observer fills)

Заполняется наблюдателем **по ходу**, тихо. Один абзац максимум.
Что фиксировать:

- **Posture shifts** — когда инспектор поменял позу относительно машины
  (отошёл, наклонился, присел). Это часто маркер cognitive load.
- **Phone-up moments** — каждый раз когда инспектор смотрит в телефон
  **больше 3 секунд подряд** не двигая рукой по машине. Поставить
  засечку. Это — runtime украл attention у машины.
- **Hand transitions** — переложил ли телефон / толщиномер / убрал перчатку.
- **Silent skips** — инспектор тапнул NEXT не отметив severity? OK,
  оставил пустым? Это **silent skip** — фиксировать item #.
- **Photo behavior** — снимает «для отчёта» или потому что *увидел*
  что-то? Это два разных режима. Помечать `P-perf` vs `P-organic`.

## Что НЕ собирается этим документом

- Telemetry / event-log из приложения — **не сейчас.**
- «Понравился UX или нет» — это performative answer, бесполезный.
- «Что бы ты добавил» — это feature request, не observation.
- Сравнение с legacy report.tsx — отложить до debrief.
